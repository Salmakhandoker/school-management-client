# 🎓 EduSphere - School Management System

EduSphere is a modern **School Management System** built with the **MERN Stack** and **TypeScript**. It streamlines school administration by providing dedicated dashboards and management tools for administrators, teachers, students, and parents. The application focuses on usability, security, and responsive design to deliver a seamless experience across devices.

* Secure user authentication

* Manage classes and sections

* Exam scheduling
* Result management

### 📊 Dashboard

* School statistics

### 🎨 User Experience

* Fully responsive design
* Clean and modern interface
* Mobile-friendly layout
* Fast navigation
* Interactive UI components

## 🚀 Installation

### Clone the repository


```

### Navigate to the project

```bash
cd edusphere
```

### Install dependencies

#### Client

```bash
cd client
npm install
```

#### Server

```bash
cd server
npm install
```

---

## ⚙️ Environment Variables

### Client

Create a `.env` file:

```env
VITE_API_URL=your_backend_url
```

### Server

Create a `.env` file:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
